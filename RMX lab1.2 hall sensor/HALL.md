# Lab 1.2: Magnetic Hall Effect Sensor Characterization (DRV5055)

ชุดทดลองศึกษาคุณลักษณะและการสอบเทียบเซนเซอร์สนามแม่เหล็ก Hall Effect (Texas Instruments DRV5055) เพื่อหาความสัมพันธ์ระหว่างระยะห่างของแท่งแม่เหล็ก (Distance), แรงดันไฟฟ้าเอาต์พุต (Output Voltage) และความหนาแน่นฟลักซ์แม่เหล็ก (Magnetic Flux Density) โดยเชื่อมต่อฮาร์ดแวร์จริงเข้ากับ Simulink และควบคุมการทดสอบด้วยสคริปต์ MATLAB

---

## 📁 รายการไฟล์ในโฟลเดอร์ (File Inventory)

| ชื่อไฟล์ | หน้าที่การทำงาน |
| :--- | :--- |
| `sensorExpoler_hall_sensor.slx` | แบบจำลอง Simulink รับสัญญาณอนุกรม (Serial COM3), แปลงสเกลแรงดัน (mV) และคำนวณฟลักซ์แม่เหล็ก (mT) ผ่านบล็อก MATLAB Function |
| `Data_hall_sensor.m` | สคริปต์ควบคุมการทดลองวัดระยะ 0–3.4 cm (ทีละ 0.2 cm), สั่งรันจุดละ 5 วินาที, หาค่าเฉลี่ย, ส่งออก CSV/TXT และพล็อตกราฟ 4 Subplots |

---

## ⚙️ ขั้นตอนการรันการทดลอง (How to Run)

1. ต่อสายบอร์ดไมโครคอนโทรลเลอร์เข้ากับคอมพิวเตอร์ และตรวจสอบว่าพอร์ต COM ตรงกับบล็อก `Host Serial Setup` ใน `sensorExpoler_hall_sensor.slx` (ค่าเริ่มต้นคือ `COM3`, Baud rate 2,000,000 bps)
2. รันสคริปต์ `Data_hall_sensor.m` ใน MATLAB Command Window
3. ปฏิบัติตามคำแนะนำบนหน้าจอ Command Window:
   - ปรับระยะห่างของแท่งแม่เหล็กไปยังระยะที่ระบุ (เช่น 0.0 cm, 0.2 cm, 0.4 cm, ...)
   - เมื่อปรับเสร็จแล้ว กด `Enter` เพื่อให้ระบบสั่งรันโมเดลอัตโนมัติ 5 วินาทีและบันทึกค่าเฉลี่ย (หรือพิมพ์ `q` แล้วกด Enter หากต้องการยกเลิก)
4. ทำซ้ำจนครบ 18 จุด (ถึงระยะ 3.4 cm) สคริปต์จะทำการ:
   - แสดงตารางสรุปผลบนหน้าต่าง Command Window
   - บันทึกผลลัพธ์ลงไฟล์ `Lab1_2_Magnetic_Results.csv` และ `Lab1_2_Magnetic_Results.txt`
   - เปิดหน้าต่างกราฟวิเคราะห์ผล 4 มิติ (4 Subplots) ให้โดยอัตโนมัติ
