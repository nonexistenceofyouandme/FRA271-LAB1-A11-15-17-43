# Lab 1.4: Strain Gauge Load Cell Calibration & Real-time Measurement

ชุดทดลองศึกษาการทำงานของโหลดเซลล์ (Strain Gauge Load Cell) ครอบคลุมการหาคุณลักษณะเชิงเส้น (Linearity), การหาสมการสอบเทียบ (Calibration Equation: y = mx + c) จากน้ำหนักมาตรฐาน 0–10 kg และการนำพารามิเตอร์กลับไปใส่ใน Simulink เพื่อวัดค่าน้ำหนักจริงแบบ Real-time เปรียบเทียบกับเครื่องชั่งดิจิทัล

---

## 📁 รายการไฟล์ในโฟลเดอร์ (File Inventory)

| ชื่อไฟล์ | หน้าที่การทำงาน |
| :--- | :--- |
| `sensorExpoler_loadcell.slx` | แบบจำลอง Simulink รับสัญญาณ Serial (COM14), กรองด้วย Moving Average, คูณ Gain m, บวก Offset c และส่งออกค่าน้ำหนัก `weight_kg` |
| `data_loadcell.m` | สคริปต์สอบเทียบ 0–10 kg (เฉลี่ยจุดละ 5 วินาที), หาสมการ $y = mx + c$ ด้วย `polyfit`, ส่งออกตาราง CSV, บันทึกค่า $m, c$ ลง TXT และพล็อตกราฟ Linearity |
| `data_loadcell_RealTime.m` | สคริปต์บันทึกค่าน้ำหนัก Real-time ต่อเนื่อง (ควบคุมหยุดด้วยการพิมพ์ 'q'), ส่งออกไฟล์ CSV และพล็อตกราฟเทียบเวลาพร้อมเส้นอ้างอิง 0 kg |

## ⚙️ ขั้นตอนการรันการทดลอง (How to Run)

### ขั้นตอนที่ 1: การสอบเทียบหาสมการ (`data_loadcell.m`)
1. ต่อสายบอร์ดเข้าคอมพิวเตอร์ และตรวจสอบว่าพอร์ต COM ตรงกับบล็อก `Host Serial Setup` ใน `sensorExpoler_loadcell.slx` (ค่าเริ่มต้นคือ `COM14`, Baud rate 2,000,000 bps)
2. รันสคริปต์ `data_loadcell.m` ใน MATLAB
3. ทำตามคำแนะนำบนหน้าจอ Command Window: วางน้ำหนักให้ได้ตามที่ระบุ (0 ถึง 10 kg) -> รอให้นิ่ง -> กด `Enter` เพื่อให้ระบบรันโมเดล 5 วินาทีและหาค่าเฉลี่ย
4. เมื่อครบ 11 จุด สคริปต์จะคำนวณสมการเส้นตรง $\text{Weight (kg)} = m \times \text{RAW} + c$, บันทึกไฟล์ `Lab1_4_LoadCell_Avg5Sec.csv`, บันทึกค่า $m$ และ $c$ ลงไฟล์ `Lab1_4_Calibration_Eq.txt` และแสดงกราฟ Linearity

### ขั้นตอนที่ 2: นำพารามิเตอร์ไปใส่ในโมเดล Simulink
1. เปิดไฟล์ `Lab1_4_Calibration_Eq.txt` ที่ได้จากขั้นตอนแรก
2. เปิดโมเดล `sensorExpoler_loadcell.slx`
3. ดับเบิลคลิกบล็อก Gain **`M`** แล้วใส่ค่าความชัน $m$
4. ดับเบิลคลิกบล็อก Constant **`C`** แล้วใส่ค่าจุดตัดแกน $c$
5. บันทึก (Save) แบบจำลอง Simulink

### ขั้นตอนที่ 3: การวัดค่าน้ำหนักต่อเนื่องแบบ Real-time (`data_loadcell_RealTime.m`)
1. รันสคริปต์ `data_loadcell_RealTime.m` แล้วกด `Enter` เพื่อเริ่มการจำลอง (ระบบจะรัน Simulink แบบไม่จำกัดเวลา)
2. ทยอยนำสิ่งของที่ทราบน้ำหนักจากการชั่งด้วยเครื่องชั่งดิจิทัลมาตรฐานมาวางบน Load Cell ทีละชิ้น (แช่ไว้ชิ้นละ 10–15 วินาทีเพื่อให้สัญญาณนิ่ง)
3. เมื่อวางครบตามแผนการทดลอง ให้พิมพ์ตัวอักษร `q` แล้วกด `Enter` เพื่อสั่งหยุด
4. สคริปต์จะบันทึกข้อมูลทุกจุดตัวอย่างลงใน `Lab1_4_Realtime_Continuous.csv` และพล็อตกราฟเปรียบเทียบเทียบกับแกนเวลาจริงทันที
